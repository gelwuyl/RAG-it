# Slide 2
Module A — Market Call
Owner: Team Leader
Cadence: Monthly, first Tuesday
Duration: 45 minutes
Output: one Market Read post, published on the fifteenth

# Slide 3
Module B — Unit Study (Agent Lead)
Owner: rotating, every agent at Frame stage or above
Cadence: Weekly
Duration: 6 to 9 minutes on camera
Rule: state one drawback of the unit, on camera, unprompted

# Slide 4
Module C — Answer Post (All Agents)
Owner: all agents
Cadence: Daily
Length: under 200 words
Rule: no call to action, no promotional language

# Slide 5
Module D — Case Clinic (Practice Committee)
Owner: Practice Committee
Cadence: Monthly, inside Market Call
Format: two live cases, brought by the agents running them
Output: one rule clarified or one rule added

# Slide 6
Conversion Path
Post -> Enquiry -> Response within 20 minutes -> Viewing -> Offer
Measured at every arrow. The arrow that leaks is the arrow we fix.

# Slide 7
Ownership Summary
Module A — Team Leader — Monthly
Module B — Frame agents and above — Weekly
Module C — All agents — Daily
Module D — Practice Committee — Monthly

# Slide 8
What This Blueprint Does Not Cover

Co-broke listings — Pathway Part C governs
