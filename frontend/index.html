02 The pipeline

A question does not go straight to a language model. It passes through five stages, and each one is inspectable in the app.

Rewrite

Questions are rarely phrased the way a document is. The query is restated before it is searched.

Retrieve

Meaning-based vector search fused with exact keyword matching, so names and IDs are not lost to paraphrase.

Rerank

A language model re-scores the candidates against the question, which catches what similarity alone misses.

Judge

A second model checks the answer against its own sources. When it cannot decide, that is reported as ungraded — never as a failure.

03 What makes it non-trivial

Hybrid retrieval, fused

Vector search finds meaning; BM25 finds exact strings. Their rankings are combined by reciprocal rank fusion, so an invoice number and a paraphrased policy are both findable.

Reranking that reads

Retrieval casts a wide net, then a language model re-scores each candidate against the actual question. Embedding distance is a proxy for relevance; this is a judgement.

Evaluation that fails open

Answers are scored for faithfulness and relevancy. A judge that times out is a broken grader, not a bad answer, so it reports ungraded — rendering that as a failure would be a confident false claim about your documents.

A benchmark you can run

46 golden questions over a 10-document corpus, including unanswerable ones — because refusing to answer is a behaviour worth measuring too.

04 Architecture
Runtime FastAPI, deployed as a single serverless function. The repo directory is read-only at runtime and the process freezes the instant a response is sent, so all writable state goes to the database.
Storage Neon Postgres with pgvector as both the application database and the vector store. Chroma is swapped in for local development behind one dispatch module.
Long jobs A background thread would be frozen the moment the response is sent, so the benchmark is sliced: the client drives a loop of bounded steps, each committing before it returns. Progress survives the function being killed.
Embeddings One fixed vector(768) column shared by every model, so models can be swapped without a migration. The config's fingerprint changes with them and invalidates stale chunks.
Configuration Chunking, retrieval and model choices are re-read from the database on every request — tuning takes effect on the next question, with no redeploy.
Frontend Vanilla JavaScript. No framework, no runtime dependencies, two entry points and one stylesheet.
